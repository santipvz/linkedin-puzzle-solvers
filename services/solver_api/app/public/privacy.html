Privacy policy

Last updated: 2 November 2026.

This policy covers Puzzle Solver and the hosted service at linkedin-puzzle-solvers.vercel.app, maintained by the project maintainer.

What the extension reads

On supported LinkedIn game pages, the extension reads the game URL and visible board elements to identify the game, locate its cells and confirm applied moves. When you request a solution, Chrome captures the visible tab locally; the extension crops the selected board region before sending an image to the chosen solver. A manually selected or incorrectly detected region can include other visible content: check that the capture covers only the board.

Online processing

Online mode sends that cropped board image over HTTPS to our API, hosted by Vercel. It is used to recognize and solve the puzzle and return the solution. The hosted application does not archive uploaded images or use them for training. Temporary uploaded files are deleted after processing. A bounded memory cache can retain derived puzzle solutions and image hashes until entries are evicted or the server instance ends.

Vercel processes the request and may retain operational metadata such as IP address, request time, endpoint and error information under its own privacy policy. We do not intentionally include board images in application logs.

Local and custom services

Local mode sends the image to the address you configure, rather than our hosted API. The operator of that service controls its retention policy. The repository's local Docker service enables capture archiving by default for debugging; its operator can disable it with DATASET_CAPTURE_ENABLED=0. Choosing a local address does not itself guarantee that the service stores no images.

Browser storage and permissions

Chrome local extension storage keeps your service address, selected game, timing preferences, board selection and last solution. These can be removed by uninstalling the extension. Settings are not synchronized to our service. Chrome requires the all-websites host permission (<all_urls>) to capture from the in-page Solve button without first opening the toolbar. This permission technically grants host access across websites. The capture code checks that the target is an active supported HTTPS LinkedIn game, and automatic content scripts run only on LinkedIn. Capture occurs when you request a solution. The permission also covers connections to your chosen solver; an extra custom-host prompt is normally unnecessary.

Data use and sharing

We do not add advertising, analytics or tracking cookies, sell user data, or use game captures for unrelated purposes. We do not request your LinkedIn credentials, messages, contacts or profile information. Game content is sent to the solver you choose only to provide the solving feature. Data use is limited to that feature and its operation.

Limited Use

Our use of data obtained through Chrome APIs complies with the Chrome Web Store User Data Policy and its Limited Use requirements. Data is used only for the disclosed puzzle-solving feature and related operation.

Your choices and contact

You can use your own service, cancel a permission request, remove optional site access in Chrome, or uninstall the extension. To ask about this policy or report a problem, use the project support page. Do not include private information in a public issue.
