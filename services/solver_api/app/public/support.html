Installation and help

  1. Install the extension, then open a supported LinkedIn game and start its board.
  2. Use the in-page Solve button immediately, or open Puzzle Solver from Chrome's extensions toolbar for preview and preferences.
  3. Keep the complete board visible, choose Online or your own local service, and select Solve & apply. Use Preview solution to inspect the result first.

Manual installation while store publication is pending

Download and extract the extension ZIP from GitHub Releases. In Chrome's extensions page, enable Developer mode and use Load unpacked to select the extracted folder. Existing installations need an extension reload and refreshed game tabs after an update.

If solving does not work

  • Start the actual puzzle and keep the complete board visible. Close overlays that cover cells.
  • If capture access is unavailable after an update, reload the extension, accept its expanded site access in Chrome, then refresh the game tab.
  • If the board contains incorrect entries from an earlier attempt, use the game's Reset control before solving again.
  • Try Board tools → Detect board or Select area when the capture is wrong.
  • For a custom service, check its address and allow access if Chrome asks. Docker normally uses http://127.0.0.1:18000.

Report a bug or request help. Include the game, extension version, service mode and exact error. Crop screenshots to the game board and exclude private account details.
